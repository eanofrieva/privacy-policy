# privacy-policy
Политика конфиденциальности

Дата последнего обновления: 25.10.2026
Настоящая Политика конфиденциальности описывает порядок обработки данных в мобильном приложении «Планировщик дел» (далее — Приложение), разработчиком которого является Анофриева Екатерина Михайловна.

* Какие данные обрабатывает Приложение

Приложение работает полностью автономно и не собирает, не хранит и не передает персональные данные пользователей третьим лицам.

Все данные, которые пользователь создает в Приложении (задачи, заметки, подзадачи, теги, настройки), хранятся только на устройстве пользователя в локальной базе данных приложения.

* Доступ к сети Интернет

Приложение не имеет доступа в Интернет: оно не запрашивает разрешение на передачу данных и не отправляет никакую информацию на внешние серверы.

* Разрешения Приложения

Приложение запрашивает следующие разрешения Android:

Уведомления — для показа напоминаний о задачах;
Точные будильники — чтобы напоминания приходили точно в указанное время;
Автозапуск после перезагрузки устройства — для восстановления напоминаний;
Биометрия / учётные данные устройства — только если пользователь включил блокировку приложения; отпечаток пальца не считывается и не сохраняется приложением, проверку выполняет операционная система;
Выбор файлов — только по явному действию пользователя, для импорта календаря из файла (.ics).

* Данные детей

Приложение не собирает данные пользователей любого возраста, включая детей.

* Изменения политики

Разработчик может обновлять настоящую Политику. Актуальная версия всегда доступна по данному адресу.
